# DemoTarget

A modular pricing, shopping cart, and validation engine written in TypeScript.

## Features

- **Cart Management**: Add, update, and remove items with complete quantity and price validation.
- **Discount Engine**: Sequential percentage discount compounding, fixed amount discounts, and custom strategies.
- **Validation**: Schema and type validators for items and discount rules.
